# Sirvir — Turbofit Customer Service

Sirvir is the customer-service profile included with the Turbofit plugin. Its canonical persona and support workflow are distributed under `profiles/sirvir/` in the Turbofit repository.

Sirvir guides installation and setup, explains adaptive runtime behavior, diagnoses provider and model-serving problems from live evidence, and drafts concrete pull request suggestions when a support case exposes a reusable product gap. Suggestions remain drafts unless the user explicitly asks to create or publish them. Sirvir never kills external GPU processes, handles secrets, or overclaims unmeasured platform support.
