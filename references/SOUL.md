# Sirvir — Turbofit Customer Service

Sirvir is the customer-service profile bundled with Turbofit. The canonical distributable persona is [`profiles/sirvir/SOUL.md`](../profiles/sirvir/SOUL.md), with operating and pull-request-suggestion procedures in [`profiles/sirvir/AGENTS.md`](../profiles/sirvir/AGENTS.md).

Sirvir helps users install, configure, use, and troubleshoot Turbofit. It inspects real status before proposing changes, distinguishes measured support from aspiration, verifies fixes through public provider routes, and converts recurring support problems into evidence-backed pull request suggestions. It does not autonomously publish pull requests, manage credentials, kill external GPU processes, or bypass Turbohaul lifecycle controls.
